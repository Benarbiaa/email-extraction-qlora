# data/real_private/ (gitignored)

Your own recruitment emails go here, anonymized, as `real_test.jsonl`.
Everything in this folder except this README is excluded from git.

Anonymization checklist (per email): person names, email addresses, phone numbers,
LinkedIn/profile URLs, street addresses, candidate/application IDs, and any internal
links with tokens. Company names may stay only if you are comfortable publishing
aggregate metrics computed on them (the emails themselves are never published).
